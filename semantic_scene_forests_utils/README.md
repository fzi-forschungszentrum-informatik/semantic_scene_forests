# semantic_scene_forests_utils

Shared utility package for small cross-package helpers.

## Task

- Provide reusable headers without introducing another runtime node.
- Centralize utility code shared by multiple packages.

## Exported Interface

- Interface library: `semantic_scene_forests_utils`
- Header: `include/semantic_scene_forests_utils/diagnostic_utils.hpp`

## Current Scope

- Diagnostic helper utilities used by packages that publish health and connectivity information.
